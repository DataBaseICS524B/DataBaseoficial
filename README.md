## Папка `src/core/` - Ядро СУБД (C++)

### `storage/` - Постоянное хранилище
| Файл | Назначение |
|------|------------|
| `StorageEngine.h/cpp` | Основной движок хранилища: save, load, delete для БД и таблиц |
| `Serializer.h/cpp` | Сериализация/десериализация (бинарный или JSON формат) |

### `catalog/` - Метаданные
| Файл | Назначение |
|------|------------|
| `Catalog.h/cpp` | Singleton-каталог всех БД, таблиц, колонок |
| `Database.h` | Класс БД (имя, список таблиц) |
| `Table.h` | Класс таблицы (имя, список колонок, данные) |
| `Column.h` | Класс колонки (имя, тип, ограничения) |

### `query/parser/` - Парсер запросов
| Файл | Назначение |
|------|------------|
| `Lexer.h/cpp` | Лексический анализ: разбивает строку на токены |
| `Parser.h/cpp` | Синтаксический анализ: проверяет грамматику и строит AST |

### `query/executor/` - Исполнитель запросов
| Файл | Назначение |
|------|------------|
| `Executor.h/cpp` | Главный исполнитель: вызывает DDL или DML Executor |
| `DDLExecutor.h/cpp` | Выполняет CREATE/DROP DATABASE и TABLE |
| `DMLExecutor.h/cpp` | Выполняет SELECT, INSERT, UPDATE, DELETE |

### `query/expressions/` - Выражения и условия
| Файл | Назначение |
|------|------------|
| `Expression.h` | Базовый класс для выражений (value, column, operation) |
| `Condition.h/cpp` | Парсинг и вычисление WHERE условий (AND, OR, NOT, сравнения) |

## Папка `src/network/` - Сетевой слой

| Файл | Назначение |
|------|------------|
| `Server.h/cpp` | TCP-сервер: accept соединений, пул потоков, управление портом |
| `ClientSession.h/cpp` | Одна клиентская сессия: чтение запросов, отправка ответов |
| `Protocol.h/cpp` | Сетевой протокол: packet format (length + data, status + length + data) |

## Папка `src/lib/` - Клиентская библиотека (C++)

| Файл | Назначение |
|------|------------|
| `DatabaseClient.h/cpp` | Основной класс для клиента: connect, execute, disconnect |
| `Connection.h/cpp` | Управление TCP-соединением с сервером |
| `exports.h` | Макросы для экспорта функций в динамической библиотеке (dllexport/dllimport) |

## Папка `src/csharp-bridge/` - Мост C++/C#

| Файл | Назначение |
|------|------------|
| `NativeBridge.h/cpp` | C-функции для P/Invoke (db_connect, db_execute, db_disconnect, db_free_string) |

## Папка `src/cli/` - Консольный интерфейс (опционально)

| Файл | Назначение |
|------|------------|
| `main.cpp` | Точка входа для сервера (парсинг аргументов --host, --port) |
| `client.cpp` | Точка входа для консольного клиента |
| `UI/ConsoleUI.h/cpp` | Отображение таблиц в консоли, форматирование вывода |
