## Роль 4: Разработчик C# GUI (WPF/WinForms)
Ответственность: Графический интерфейс пользователя на C#

### ТЗ:

Поля ввода: Host, Port, кнопка "Подключиться"

Таблица для отображения результатов SELECT

Для SELECT: табличное представление с заголовками столбцов

Для INSERT/UPDATE/DELETE: сообщение "Affected rows: X"
